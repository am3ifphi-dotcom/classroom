# 放課後、存在しない七限目

『偏差値60の教室から✝本質✝が漏れ出している件について』の人物・舞台を用いた、**原作にない独自エピソード**の短編探索・アクションRPG。

三重県臣を操作し、両馬二郎と桐葉高校の北棟を歩きます。17時06分から動かない時計、消える自販機のボタン、視聴者ゼロの配信。3つの異変を調査して「存在しない七限目」に決着をつけます。

## 遊ぶ

### ライブプレビュー

このセッションのライブプレビュー（ポート5173）で「放課後をはじめる」を選んでください。

### 単一HTML版

`release/after-hours.html` をダウンロードし、モダンブラウザで開けます。**画像、フォント、BGM、効果音をすべて内包**しており、サーバー・CDN・ネット接続は不要です（約22MB）。初回の音は開始操作後に再生されます。

セーブはブラウザのlocalStorageです。file:// における保存の扱いはブラウザ依存です。保存できない環境ではゲーム内に通知します。確実な同一保存先でのプレイにはHTTP版を使用してください。

### 開発版

```sh
npm ci
npm run dev -- --port 5173
```

0.0.0.0 にバインドします。プレビュー用ホスト名を受け入れます。外部バックエンドはありません。

### 配布用ビルド

```sh
npm run build
node scripts/export-single.mjs /希望する場所/after-hours.html
```

`dist/` は静的ホスティング用です。単一HTML書き出しは、Viteの出力中のローカルアセットをData URLに置き換えます。

## 操作

| 操作 | PC | タッチ端末 |
|---|---|---|
| 移動 | WASD / 矢印 / 床クリック | 左下の仮想スティック / 床タップ |
| 走る | Shift + 移動 | — |
| 話す・調べる・会話送り | E / Enter（会話送りのみ Space も可） | 「調べる」/ 会話の「つづける」 |
| 記録 | J | 右下の「記録」 |
| 持ち物 | I | 右下の「鞄」 |

## 実装内容

- 連続した5エリア：2年B組、地理準備室、渡り廊下、踊り場、放送準備室。
- 5人のキャラクター。既存LPCパーツを提供立ち絵に合わせて合成・頭部編集。4方向9コマ（静止1＋歩行8）、詠唱7コマ。
- 足元の当たり判定、クリック経路探索、追従する両馬、カメラ追従、前後関係のYソート。
- 3つの探索目標、3つの中間の番人、最後の番人、2つの結末。
- **マップ上のアクション戦闘**。最初の事件後に現れる8体の答案の巡回敵、追跡、赤い攻撃予告、回避、光弾、範囲攻撃。番人から遠く離れると仕切り直し。敗北時は教室で回復し、欠片・記録は失いません。
- 次にすること・行き先・推奨順序を示すストーリーガイド。金色の道しるべとミニマップの経路表示。寄り道・別の順番での攻略も可能。
- 7件の観測記録、レベルアップ、持ち物、回復、NPC会話、記録数による最終選択肢。
- 夕方の光条、局所的な異変の光、外部テクスチャによる粒子・魔法演出、カメラ揺れと演出軽減設定。
- 自動・手動セーブ、継続プレイ、再開時のデータ検証、音量設定の保存。
- キーボード・マウス・タッチ対応。アプリ用のサイドバーなどは表示せず、ゲーム内UIのみ。

## テスト

```sh
npm test
```

20件のロジックテスト：保存互換、全目的地・敵配置の到達性、攻撃の射程・向き、壁越し攻撃防止、予告・回避・無敵時間、消費資源、番人の勝利・離脱、ガイド分岐。

ブラウザ実機相当テスト（Chromium / Playwright）も実施しました。詳細は [QA.md](QA.md)。`scripts/e2e-action.mjs` と `scripts/qa-action.mjs` を含めています。これらは開発サーバーが必要です。通常の環境ではPlaywright同梱ブラウザを利用できます。本環境ではネットワーク制限のためnpm配布の `@sparticuz/chromium` を使用しています。

素材の再合成にはPython/Pillowが必要です。`scripts/characters.py` は外部LPCパーツを取得し、`scripts/compose_assets.py` が合成します。GitHub取得には認証済みの `gh` を使います。提供画像原寸は同梱していないため、会話ポートレートの再生成には該当のユーザー提供画像が必要です。通常ビルドにはPNGを同梱済みです。

## 頭部の再編集

提供立ち絵を基準に、前髪の重さ・毛先の輪郭・細い目元・眼鏡を再編集。寺地はユーザーの補足どおり、目元を隠さない短めで爽やかなセンター分けです。頭部の編集元は `art/heads/` と `scripts/pixel_heads.py`。128pxセルで書き出していますが、ゲーム内の大きさ・足元・当たり判定は以前と同じ64pxセル相当です。

```sh
.venv/bin/python scripts/characters.py
.venv/bin/python scripts/compose_assets.py
.venv/bin/python scripts/monsters.py
.venv/bin/python scripts/verify_character_art.py
.venv/bin/python scripts/preview_character_walk.py
```

人物の完全な似顔絵精度を保証するものではありません。比較画像と実際のゲームで判断できるよう、参照・修正内容を同梱しています。

## 導入の改稿

開始直後には敵を置かず、普通の帰り支度から始まります。両馬と合流して下校口を調べると、実際に教室へ戻され、黒板の新しい一行を確かめに行く流れです。初回の黒板の場面で、文字が赤い×のついた答案になること、黒板消しで払いのけられること、戦わないと帰れない理由を描きます。

骸骨画像・未起動の半透明モンスター表示は撤去。最初の黒板の事件の後は、自販機と放送室のどちらからでも進められます。序盤にNPCを訪ねた場合は日常の会話になり、事件後の会話・記録入手を飛ばしません。

旧セーブの欠片・記録は維持します。**新しい導入を体験するには「最初から」**を選んでください（既存の進行は確認ダイアログの後に上書きされます）。
